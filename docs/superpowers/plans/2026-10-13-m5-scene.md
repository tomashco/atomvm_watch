# m5_scene Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let apps on the M5StickC Plus 2 describe their screen as `avm_scene` scenes with
AtomGL-style display lists, drawn through `atomvm_m5`'s `m5_display`, identically in the browser
emulator and on the watch.

**Architecture:** A new rebar3 library `m5_scene/` provides the two processes `avm_scene` needs: a
display server (`m5_scene_display`: validates a display list, diffs it against the previous frame
and draws only the dirty rectangles with `m5_display` calls) and an input server
(`m5_scene_input`: polls the buttons and sends `{input_event, ...}`). The diff and drawing logic
lives in pure modules (`m5_scene_render`, `m5_scene_image`) tested on the host BEAM. Two missing
`m5_display` functions (`set_text_color/2`, `push_image/5`) come from a firmware patch to
`atomvm_m5`, mirrored in the `m5_emu` emulator (Erlang side and the TypeScript canvas renderer),
which also gains clip rectangles.

**Tech Stack:** Erlang/OTP (rebar3, eunit) for `m5_scene` and `m5_emu`; Elixir (mix, exatomvm)
for `examples/scenes`; TypeScript (vitest, Playwright) for the web emulator; C++ (ESP-IDF,
M5GFX) for the `atomvm_m5` patch; AtomVM v0.7.0-beta.0; `avm_scene` 0.2.0 from Hex.

**Spec:** `docs/superpowers/specs/2026-10-13-m5-scene-design.md`

## Global Constraints

- Branch `m5-scene`. Run every command inside the devenv shell (`direnv` loads it; otherwise
  prefix with `devenv shell --`).
- AtomVM `v0.7.0-beta.0`, `atomvm_m5` pinned at `968508c77c90af5a0109bcd7f0e28a5fa8624c02`
  (`versions.env`), `avm_scene` `~> 0.2.0` from Hex.
- `m5_scene` runs on AtomVM: in `src/` use only the functions the code below uses (checked
  against `vendor/AtomVM-src` at v0.7.0-beta.0: `lists:sublist/2`, `append/1`, `keymember/3`,
  `keydelete/3`, `maps:find/2`, `put/3`, `binary:part/3`, `unicode:characters_to_*`, `math:sqrt/1`,
  `base64:encode/1`). No `io_lib`, binary comprehensions, `logger` or `ets` in `src/`. Check
  `vendor/AtomVM-src/libs/estdlib/src` before adding any other stdlib call.
- `m5_scene` never calls an `m5_*` module through a variable: dynamic calls go to its own wrapper
  modules (`m5_scene_m5`, `m5_scene_buttons`), which call `m5_display`, `m5` and `m5_btn_*`
  statically, so the NIFs resolve on the device the same way they do for `examples/clock`.
- Display list rules (spec §4): the first item is on top; colours are the low 24 bits; `rect` and
  `text` clamp values to ±32767; image and shape values outside ±32767 make the item invalid;
  `default16px` = text size 2 (12×16 per char), `m5_font1`..`m5_font4` = sizes 1..4 (6×8 × size).
- Invalid items are logged as `invalid display list item N (Cmd/Arity): Reason` (or
  `invalid display list item N: not a command tuple`), at most 3 per update plus
  `K more invalid display list items`; an improper list returns `{error, invalid_display_list}`
  and logs `invalid display list: not a proper list`.
- Full redraw when the dirty area is over half the screen, on the first frame, and when the same
  items only changed order.
- Images: RGBA → RGB565 big-endian; opaque `Bg` blends, `transparent` pushes runs of alpha ≥ 128.
- `m5_scene_input` owns `m5:update/0`; button names `a`, `b`, `pwr`; events `pressed`, `hold`,
  `released`, `click`, `double_click`, checked in that order on every poll.

## Review Focus

- **A frame identical to the previous one** must draw nothing, not even `start_write`: scenes push
  on every input event, so this is the common case. Pinned in Task 4 (`unchanged_frame_draws_nothing_test`).
- **A scene that pushes a bad frame** (improper list, garbage items) must keep the last good frame on
  screen and keep the next diff correct. Pinned in Task 5 (`improper_list_keeps_last_frame_test`).
- **A subscriber that dies** (a scene that crashed and was restarted) must not make the input server
  crash or leak. Pinned in Task 6 (`dead_subscriber_is_removed_test`).
- **Text with an opaque background over other items** must cover them exactly in its character box,
  also when `Fg` equals `Bg`. Pinned in Task 4 (`text_ops_test`).
- **Changes entirely off screen** must draw nothing instead of an empty clip sequence. Pinned in
  Task 4 (`offscreen_change_draws_nothing_test`).

```ts
// examples/scenes (avm_scene scenes drawn by m5_scene) running in the real AtomVM wasm VM.
// The app runs at rotation 1 (240x135 landscape). The canvas is the native 135x240 framebuffer:
// logical (x, y) is native (134 - y, x). Alpha is included so a never-drawn canvas can't pass.
```

`m5_scene/src/m5_scene_render.erl`:

```erlang
%% Pure functions behind m5_scene_display: display list validation and bounding boxes, and the
%% draw plan (plan/4). No side effects, so everything here is tested on the host BEAM.
-module(m5_scene_render).
-export([validate/1, bbox/1]).

-define(MAXC, 32767).
-define(LOG_MAX, 3).

%% Checks every item of a display list and normalizes the valid ones: rect and text values clamped
%% to +-32767, colours masked to 24 bits, text as a UTF-8 binary with its character count, fonts
%% as an M5GFX text size. Returns {ok, Items, LogLines}, or {error, invalid_display_list} when
%% List is not a proper list.
validate(List) ->
    case is_proper(List) of
        true -> validate(List, 1, [], [], []);
        false -> {error, invalid_display_list}
    end.

is_proper([]) -> true;
is_proper([_ | T]) -> is_proper(T);
is_proper(_) -> false.

validate([], _N, Items, Invalid, Warnings) ->
    {ok, lists:reverse(Items), invalid_lines(lists:reverse(Invalid)) ++ lists:reverse(Warnings)};
validate([Item | Rest], N, Items, Invalid, Warnings) ->
    case item(Item) of
        {ok, I} -> validate(Rest, N + 1, [I | Items], Invalid, Warnings);
        {ok, I, W} -> validate(Rest, N + 1, [I | Items], Invalid, [W | Warnings]);
        {error, Reason} -> validate(Rest, N + 1, Items, [{N, label(Item), Reason} | Invalid], Warnings)
    end.

item(T) when is_tuple(T), tuple_size(T) > 0 ->
    case element(1, T) of
        rect -> rect(T);
        text -> text(T);
        image -> image(T);
        scaled_cropped_image -> scaled(T);
        rounded_rect -> rounded_rect(T);
        circle -> circle(T);
        ellipse -> ellipse(T);
        line -> line(T);
        arc -> {error, "unsupported command"};
        polygon -> {error, "unsupported command"};
        _ -> {error, "unknown command"}
    end;
item(_) ->
    {error, "not a command tuple"}.

rect({rect, X, Y, W, H, C}) ->
    case ints([X, Y, W, H, C]) of
        true -> {ok, {rect, clamp(X), clamp(Y), clamp(W), clamp(H), C band 16#FFFFFF}};
        false -> {error, "bad position, size or color"}
    end;
rect(_) ->
    {error, "wrong arity"}.

text({text, X, Y, Font, Fg, Bg, Text}) ->
    case ints([X, Y, Fg]) andalso is_bg(Bg) of
        false ->
            {error, "bad position or color"};
        true when not is_atom(Font) ->
            {error, "bad font"};
        true ->
            case utf8(Text) of
                error ->
                    {error, "bad text"};
                Bin ->
                    I = {text, clamp(X), clamp(Y), font_size(Font), Fg band 16#FFFFFF, bg(Bg), Bin,
                         chars(Bin)},
                    case lists:member(Font, [default16px, m5_font1, m5_font2, m5_font3, m5_font4]) of
                        true -> {ok, I};
                        false -> {ok, I, iolist_to_binary(["unsupported font: ", atom_to_list(Font)])}
                    end
            end
    end;
text(_) ->
    {error, "wrong arity"}.

image({image, X, Y, Bg, Img}) ->
    case in_range([X, Y]) andalso is_bg(Bg) of
        false ->
            {error, "bad position or color"};
        true ->
            case image_tuple(Img) of
                {ok, W, H, Px} -> {ok, {image, X, Y, bg(Bg), W, H, Px}};
                error -> {error, "bad image"}
            end
    end;
image(_) ->
    {error, "wrong arity"}.

scaled({scaled_cropped_image, X, Y, W, H, Bg, SX, SY, XS, YS, Opts, Img}) ->
    case in_range([X, Y, W, H, SX, SY, XS, YS]) andalso is_bg(Bg) andalso W >= 0 andalso H >= 0
         andalso XS >= 1 andalso YS >= 1 of
        false ->
            {error, "bad position, size, color, source or scale"};
        true ->
            case image_tuple(Img) of
                error ->
                    {error, "bad image"};
                {ok, IW, IH, Px} when SX >= 0, SX < IW, SY >= 0, SY < IH ->
                    {ok, {scaled, X, Y, min(W, (IW - SX) * XS), min(H, (IH - SY) * YS), bg(Bg),
                          SX, SY, XS, YS, flag(flip_x, Opts), flag(flip_y, Opts), IW, Px}};
                {ok, _, _, _} ->
                    {error, "source outside the image"}
            end
    end;
scaled(_) ->
    {error, "wrong arity"}.

rounded_rect({rounded_rect, X, Y, W, H, R, C}) ->
    case in_range([X, Y, W, H, R]) andalso is_integer(C) andalso R >= 0 of
        true -> {ok, {rounded_rect, X, Y, W, H, min(R, max(0, (min(W, H) - 1) div 2)), C band 16#FFFFFF}};
        false -> {error, "bad position, size, radius or color"}
    end;
rounded_rect(_) ->
    {error, "wrong arity"}.

circle({circle, CX, CY, R, C}) ->
    case in_range([CX, CY, R]) andalso is_integer(C) andalso R > 0 of
        true -> {ok, {circle, CX, CY, R, C band 16#FFFFFF}};
        false -> {error, "bad center, radius or color"}
    end;
circle(_) ->
    {error, "wrong arity"}.

ellipse({ellipse, CX, CY, RX, RY, C}) ->
    case in_range([CX, CY, RX, RY]) andalso is_integer(C) andalso RX > 0 andalso RY > 0 of
        true -> {ok, {ellipse, CX, CY, RX, RY, C band 16#FFFFFF}};
        false -> {error, "bad center, radii or color"}
    end;
ellipse(_) ->
    {error, "wrong arity"}.

line({line, X1, Y1, X2, Y2, T, C}) ->
    case in_range([X1, Y1, X2, Y2, T]) andalso is_integer(C) andalso T >= 1 of
        true -> {ok, {line, X1, Y1, X2, Y2, T, C band 16#FFFFFF}};
        false -> {error, "bad points, thickness or color"}
    end;
line(_) ->
    {error, "wrong arity"}.

                                       W =< ?MAXC, H =< ?MAXC, is_binary(Px),
                                       byte_size(Px) >= W * H * 4 ->
    {ok, W, H, Px};
image_tuple(_) ->
    error.

flag(F, Opts) when is_list(Opts) -> lists:member(F, Opts) orelse lists:member({F, true}, Opts);
flag(_F, _Opts) -> false.

font_size(m5_font2) -> 2;
font_size(m5_font3) -> 3;
font_size(m5_font4) -> 4;
font_size(_) -> 2.

utf8(B) when is_binary(B) -> B;
utf8(L) when is_list(L) ->
    case catch unicode:characters_to_binary(L) of
        B when is_binary(B) -> B;
        _ -> error
    end;
utf8(_) -> error.

%% Malformed UTF-8 counts one character per byte, as m5_emu does.
chars(Bin) ->
    case catch unicode:characters_to_list(Bin) of
        L when is_list(L) -> length(L);
        _ -> byte_size(Bin)
    end.

is_bg(transparent) -> true;
is_bg(C) -> is_integer(C).

bg(transparent) -> transparent;
bg(C) -> C band 16#FFFFFF.

ints(L) -> lists:all(fun erlang:is_integer/1, L).

invalid_lines(Invalid) ->
    Shown = lists:sublist(Invalid, ?LOG_MAX),
    [invalid_line(I) || I <- Shown] ++ more_line(length(Invalid) - length(Shown)).

more_line(0) -> [];
more_line(1) -> [<<"1 more invalid display list item">>];
more_line(K) -> [iolist_to_binary([integer_to_list(K), " more invalid display list items"])].

invalid_line({N, none, Reason}) ->
    iolist_to_binary(["invalid display list item ", integer_to_list(N), ": ", Reason]);
invalid_line({N, {Cmd, Arity}, Reason}) ->
    iolist_to_binary(["invalid display list item ", integer_to_list(N), " (", Cmd, "/",
                      integer_to_list(Arity), "): ", Reason]).

label(T) when is_tuple(T), tuple_size(T) > 0 ->
    case element(1, T) of
        A when is_atom(A) -> {atom_to_list(A), tuple_size(T)};
        _ -> {"tuple", tuple_size(T)}
    end;
label(_) ->
    none.

%% Bounding box {X, Y, W, H} of a validated item. Text uses M5GFX's built-in font: 6x8 pixels per
%% character times the text size. A line is padded by half its thickness for the approximation.
bbox({rect, X, Y, W, H, _}) -> {X, Y, W, H};
bbox({text, X, Y, S, _, _, _, N}) -> {X, Y, N * 6 * S, 8 * S};
bbox({image, X, Y, _, W, H, _}) -> {X, Y, W, H};
bbox({scaled, X, Y, W, H, _, _, _, _, _, _, _, _, _}) -> {X, Y, W, H};
bbox({rounded_rect, X, Y, W, H, _, _}) -> {X, Y, W, H};
bbox({circle, CX, CY, R, _}) -> {CX - R, CY - R, 2 * R + 1, 2 * R + 1};
bbox({ellipse, CX, CY, RX, RY, _}) -> {CX - RX, CY - RY, 2 * RX + 1, 2 * RY + 1};
bbox({line, X1, Y1, X2, Y2, T, _}) ->
    P = line_pad(T),
    {min(X1, X2) - P, min(Y1, Y2) - P, abs(X2 - X1) + 1 + 2 * P, abs(Y2 - Y1) + 1 + 2 * P}.

line_pad(1) -> 0;
line_pad(T) -> (T - 1) div 2 + 1.
```

```erlang
%% RGBA8888 images to RGB565 push_image operations, with a cache so an image that stays in the
%% display list is converted once. Pure functions.
-module(m5_scene_image).
-export([ops/2, is_image/1, retain/2, rgb565/3, blend/3]).

is_image(Item) -> element(1, Item) =:= image orelse element(1, Item) =:= scaled.

%% The converted runs don't depend on the position, so a moved image keeps its cache entry.
key({image, _X, _Y, Bg, W, H, Px}) ->
    {image, Bg, W, H, Px};
key({scaled, _X, _Y, W, H, Bg, SX, SY, XS, YS, FX, FY, IW, Px}) ->
    {scaled, W, H, Bg, SX, SY, XS, YS, FX, FY, IW, Px}.

%% push_image operations for an image item, and the cache with its entry added.
ops(Item, Cache) ->
    Key = key(Item),
    Runs =
        case maps:find(Key, Cache) of
            {ok, R} -> R;
            error -> convert(Item)
        end,
    X = element(2, Item),
    Y = element(3, Item),
    {[{push_image, [X + DX, Y + DY, W, H, Bin]} || {DX, DY, W, H, Bin} <- Runs],
     maps:put(Key, Runs, Cache)}.

%% The cache restricted to the given image items' entries.
retain(Cache, Images) ->
    lists:foldl(
        fun(I, Acc) ->
            K = key(I),
            case maps:find(K, Cache) of
                {ok, V} -> maps:put(K, V, Acc);
                error -> Acc
            end
        end, #{}, Images).

convert({image, _X, _Y, Bg, W, H, Px}) ->
    runs(W, H, Bg, fun(DX, DY) -> rgba(Px, DY * W + DX) end);
convert({scaled, _X, _Y, W, H, Bg, SX, SY, XS, YS, FX, FY, IW, Px}) ->
    Pixel = fun(DX, DY) ->
                CX = case FX of true -> W - 1 - DX; false -> DX end,
                CY = case FY of true -> H - 1 - DY; false -> DY end,
                rgba(Px, (SY + CY div YS) * IW + SX + CX div XS)
            end,
    runs(W, H, Bg, Pixel).

rgba(Px, I) ->
    <<R, G, B, A>> = binary:part(Px, I * 4, 4),
    {R, G, B, A}.

%% Runs are {DX, DY, W, H, Rgb565}. Opaque background: one run for the whole image, alpha-blended
%% against Bg. transparent: per row, one run for each stretch of pixels with alpha >= 128, unblended.
runs(W, H, _Bg, _Pixel) when W =< 0; H =< 0 ->
    [];
runs(W, H, transparent, Pixel) ->
    lists:append([row_runs(W, DY, Pixel) || DY <- lists:seq(0, H - 1)]);
runs(W, H, Bg, Pixel) ->
    BR = (Bg bsr 16) band 255,
    BG = (Bg bsr 8) band 255,
    BB = Bg band 255,
    Bin = iolist_to_binary(
            [begin
                 {R, G, B, A} = Pixel(DX, DY),
                 rgb565(blend(R, A, BR), blend(G, A, BG), blend(B, A, BB))
             end || DY <- lists:seq(0, H - 1), DX <- lists:seq(0, W - 1)]),
    [{0, 0, W, H, Bin}].

row_runs(W, DY, Pixel) ->
    {Done, Open} =
        lists:foldl(
            fun(DX, {Acc, Cur}) ->
                case Pixel(DX, DY) of
                    {R, G, B, A} when A >= 128 ->
                        case Cur of
                            none -> {Acc, {DX, [rgb565(R, G, B)]}};
                            {Start, Px} -> {Acc, {Start, [rgb565(R, G, B) | Px]}}
                        end;
                    _ ->
                        {close(Cur, DY, Acc), none}
                end
            end, {[], none}, lists:seq(0, W - 1)),
    lists:reverse(close(Open, DY, Done)).

close(none, _DY, Acc) -> Acc;
close({Start, Px}, DY, Acc) -> [{Start, DY, length(Px), 1, iolist_to_binary(lists:reverse(Px))} | Acc].

blend(S, A, B) -> (S * A + B * (255 - A)) div 255.

rgb565(R, G, B) ->
    V = ((R bsr 3) bsl 11) bor ((G bsr 2) bsl 5) bor (B bsr 3),
    <<V:16/big>>.
```

```erlang
%% The operations that turn the previous frame Old (validated items, or none before the first
%% frame) into New on a W x H screen with background Bg. Returns {Ops, Cache1}: Ops is a list of
%% {Function, Args} for the display module, Cache1 the image cache restricted to New's images.
plan(Same, Same, _Screen, Cache) ->
    {[], Cache};
plan(Old, New, {W, H, Bg}, Cache) ->
    Screen = {0, 0, W, H},
    {Body, Cache1} =
        case dirty(Old, New, Screen) of
            full -> region(Screen, New, Bg, false, Cache);
            Rects -> regions(Rects, New, Bg, Cache)
        end,
    Ops =
        case Body of
            [] -> [];
            _ -> [{start_write, []}] ++ Body ++ [{end_write, []}]
        end,
    {Ops, m5_scene_image:retain(Cache1, [I || I <- New, m5_scene_image:is_image(I)])}.

%% full, or the merged dirty rectangles: the boxes of the items added and removed, clipped to the
%% screen. Same items in another order change the stacking everywhere, so that is full too.
dirty(none, _New, _Screen) ->
    full;
dirty(Old, New, {_, _, W, H} = Screen) ->
    case subtract(Old, New) ++ subtract(New, Old) of
        [] ->
            full;
        Changed ->
            Rects = merge([R || I <- Changed, R <- [clip(bbox(I), Screen)], R =/= empty]),
            case area(Rects) * 2 > W * H of
                true -> full;
                false -> Rects
            end
    end.

regions(Rects, Items, Bg, Cache) ->
    lists:foldl(
        fun(R, {Ops, C}) ->
            {Ops1, C1} = region(R, Items, Bg, true, C),
            {Ops ++ Ops1, C1}
        end, {[], Cache}, Rects).

%% One redraw region: fill it with the background, then draw the items that overlap it from last
%% to first, so the first item ends on top. Clip is true for a dirty rectangle.
region({X, Y, W, H} = R, Items, Bg, Clip, Cache) ->
    {Draw, Cache1} = draw_all([I || I <- lists:reverse(Items), overlaps(bbox(I), R)], Cache),
    Fill = [{fill_rect, [X, Y, W, H, Bg]}],
    case Clip of
        true -> {[{set_clip_rect, [X, Y, W, H]}] ++ Fill ++ Draw ++ [{clear_clip_rect, []}], Cache1};
        false -> {Fill ++ Draw, Cache1}
    end.

draw_all(Items, Cache) ->
    lists:foldl(
        fun(I, {Ops, C}) ->
            {Ops1, C1} = draw(I, C),
            {Ops ++ Ops1, C1}
        end, {[], Cache}, Items).

draw({rect, X, Y, W, H, C}, Cache) ->
    {[{fill_rect, [X, Y, W, H, C]}], Cache};
draw({text, X, Y, S, Fg, Bg, Bin, N}, Cache) ->
    Box = case Bg of
              transparent -> [];
              _ -> [{fill_rect, [X, Y, N * 6 * S, 8 * S, Bg]}]
          end,
    %% The same colour twice is M5GFX's transparent text background.
    {Box ++ [{set_text_size, [S]}, {set_text_color, [Fg, Fg]}, {draw_string, [Bin, X, Y]}], Cache};
draw({rounded_rect, X, Y, W, H, R, C}, Cache) ->
    {[{fill_round_rect, [X, Y, W, H, R, C]}], Cache};
draw({circle, CX, CY, R, C}, Cache) ->
    {[{fill_circle, [CX, CY, R, C]}], Cache};
draw({ellipse, CX, CY, RX, RY, C}, Cache) ->
    {[{fill_ellipse, [CX, CY, RX, RY, C]}], Cache};
draw({line, X1, Y1, X2, Y2, 1, C}, Cache) ->
    {[{draw_line, [X1, Y1, X2, Y2, C]}], Cache};
draw({line, X1, Y1, X2, Y2, T, C}, Cache) ->
    {thick_line(X1, Y1, X2, Y2, T, C), Cache};
draw(Image, Cache) ->
    m5_scene_image:ops(Image, Cache).

%% M5GFX in atomvm_m5 has no wide line: approximate with a quad of two triangles, offset by half
%% the thickness across the line, plus round caps from thickness 3.
thick_line(X, Y, X, Y, T, C) ->
    [{fill_circle, [X, Y, (T - 1) div 2, C]}];
thick_line(X1, Y1, X2, Y2, T, C) ->
    DX = X2 - X1,
    DY = Y2 - Y1,
    Len = math:sqrt(DX * DX + DY * DY),
    Half = (T - 1) / 2,
    OX = round(-DY * Half / Len),
    OY = round(DX * Half / Len),
    Quad = [{fill_triangle, [X1 + OX, Y1 + OY, X2 + OX, Y2 + OY, X2 - OX, Y2 - OY, C]},
            {fill_triangle, [X1 + OX, Y1 + OY, X2 - OX, Y2 - OY, X1 - OX, Y1 - OY, C]}],
    case T >= 3 of
        true -> Quad ++ [{fill_circle, [X1, Y1, (T - 1) div 2, C]}, {fill_circle, [X2, Y2, (T - 1) div 2, C]}];
        false -> Quad
    end.

clip({X, Y, W, H}, {SX, SY, SW, SH}) ->
    X0 = max(X, SX), Y0 = max(Y, SY),
    X1 = min(X + W, SX + SW), Y1 = min(Y + H, SY + SH),
    case X1 > X0 andalso Y1 > Y0 of
        true -> {X0, Y0, X1 - X0, Y1 - Y0};
        false -> empty
    end.

overlaps({X1, Y1, W1, H1}, {X2, Y2, W2, H2}) ->
    W1 > 0 andalso H1 > 0 andalso X1 < X2 + W2 andalso X2 < X1 + W1
        andalso Y1 < Y2 + H2 andalso Y2 < Y1 + H1.

%% Merges overlapping rectangles into their bounding union until none overlap.
merge(Rects) -> merge(Rects, []).

merge([], Acc) ->
    lists:reverse(Acc);
merge([R | Rest], Acc) ->
    case take_overlapping(R, lists:reverse(Acc) ++ Rest, []) of
        none -> merge(Rest, [R | Acc]);
        {Other, Remaining} -> merge([union(R, Other) | Remaining], [])
    end.

take_overlapping(_R, [], _Seen) -> none;
take_overlapping(R, [O | Rest], Seen) ->
    case overlaps(R, O) of
        true -> {O, lists:reverse(Seen) ++ Rest};
        false -> take_overlapping(R, Rest, [O | Seen])
    end.

union({X1, Y1, W1, H1}, {X2, Y2, W2, H2}) ->
    X = min(X1, X2), Y = min(Y1, Y2),
    {X, Y, max(X1 + W1, X2 + W2) - X, max(Y1 + H1, Y2 + H2) - Y}.

area(Rects) -> lists:foldl(fun({_, _, W, H}, A) -> A + W * H end, 0, Rects).

%% L minus one occurrence of each element of R (multiset difference; no -- on AtomVM).
subtract(L, []) -> L;
subtract(L, [X | Xs]) -> subtract(delete(X, L), Xs).

delete(_X, []) -> [];
delete(X, [X | T]) -> T;
delete(X, [H | T]) -> [H | delete(X, T)].
```

```erlang
%% avm_scene's display server for m5_display: avm_scene calls call(Pid, {update, DisplayList}) for
%% every pushed frame. Keeps the last valid frame and draws only what changed.
-module(m5_scene_display).
-behaviour(gen_server).
-export([start_link/1, call/2]).
-export([init/1, handle_call/3, handle_cast/2, handle_info/2]).

%% Opts: #{display := module(), width := integer(), height := integer(), background := integer()}.
start_link(Opts) ->
    gen_server:start_link(?MODULE, Opts, []).

call(Pid, Msg) ->
    gen_server:call(Pid, Msg, infinity).

init(#{display := D, width := W, height := H, background := Bg}) ->
    {ok, #{display => D, screen => {W, H, Bg band 16#FFFFFF}, last => none, cache => #{}}}.

handle_call({update, List}, _From, #{display := D, screen := Screen, last := Last, cache := Cache} = S) ->
    case m5_scene_render:validate(List) of
        {error, invalid_display_list} ->
            log(<<"invalid display list: not a proper list">>),
            {reply, {error, invalid_display_list}, S};
        {ok, Items, Lines} ->
            lists:foreach(fun log/1, Lines),
            {Ops, Cache1} = m5_scene_render:plan(Last, Items, Screen, Cache),
            lists:foreach(fun({F, A}) -> apply(D, F, A) end, Ops),
            {reply, ok, S#{last := Items, cache := Cache1}}
    end;
handle_call(_Msg, _From, S) ->
    {reply, {error, unknown_call}, S}.

handle_cast(_Msg, S) -> {noreply, S}.
handle_info(_Msg, S) -> {noreply, S}.

log(Line) -> io:format("~s~n", [Line]).
```

```erlang
%% avm_scene's input server for the M5 buttons. Every poll_ms it calls the button module's update/0
%% (m5:update/0 by default, so this process owns it) and sends each button state change to the
%% subscribers as {input_event, self(), Ts, {button, Name, Event}}.
-module(m5_scene_input).
-behaviour(gen_server).
-export([start_link/1, poll/1]).
-export([init/1, handle_call/3, handle_cast/2, handle_info/2]).

-define(BUTTONS, [a, b, pwr]).
%% Checked in this order on each poll. M5Unified reports was_clicked on the release of a short
%% press and was_double_clicked later, once the click count is decided; a held press reports
%% was_hold and no click.
-define(STATES, [{was_pressed, pressed}, {was_hold, hold}, {was_released, released},
                 {was_clicked, click}, {was_double_clicked, double_click}]).

%% Opts: #{buttons := module(), poll_ms := pos_integer() | infinity}.
start_link(Opts) ->
    gen_server:start_link(?MODULE, Opts, []).

%% One synchronous poll (tests use poll_ms => infinity and call this).
poll(Pid) ->
    gen_server:call(Pid, poll).

init(#{buttons := B, poll_ms := Ms}) ->
    schedule(Ms),
    {ok, #{buttons => B, poll_ms => Ms, subs => []}}.

handle_call({subscribe_input}, {Pid, _Tag}, #{subs := Subs} = S) ->
    case lists:keymember(Pid, 1, Subs) of
        true ->
            {reply, ok, S};
        false ->
            Ref = erlang:monitor(process, Pid),
            {reply, ok, S#{subs := [{Pid, Ref} | Subs]}}
    end;
handle_call(poll, _From, S) ->
    do_poll(S),
    {reply, ok, S};
handle_call(_Msg, _From, S) ->
    {reply, {error, unknown_call}, S}.

handle_info(poll, #{poll_ms := Ms} = S) ->
    do_poll(S),
    schedule(Ms),
    {noreply, S};
handle_info({'DOWN', Ref, process, _Pid, _Reason}, #{subs := Subs} = S) ->
    {noreply, S#{subs := lists:keydelete(Ref, 2, Subs)}};
handle_info(_Msg, S) ->
    {noreply, S}.

handle_cast(_Msg, S) -> {noreply, S}.

do_poll(#{buttons := B, subs := Subs}) ->
    B:update(),
    Events = [{button, Name, Ev} || Name <- ?BUTTONS, {Query, Ev} <- ?STATES, B:read(Name, Query)],
    Ts = erlang:system_time(millisecond),
    lists:foreach(fun(E) -> [Pid ! {input_event, self(), Ts, E} || {Pid, _} <- Subs] end, Events).

schedule(infinity) -> ok;
schedule(Ms) -> erlang:send_after(Ms, self(), poll), ok.
```

```cpp
// push_image(X, Y, W, H, Rgb565): W * H big-endian RGB565 pixels (2 bytes each).
static term nif_display_push_image(Context* ctx, int argc, term argv[])
{
    UNUSED(argc);
    for (int i = 0; i < 4; i++) {
        VALIDATE_VALUE(argv[i], term_is_integer);
    }
    VALIDATE_VALUE(argv[4], term_is_binary);
    avm_int_t x = term_to_int(argv[0]);
    avm_int_t y = term_to_int(argv[1]);
    avm_int_t w = term_to_int(argv[2]);
    avm_int_t h = term_to_int(argv[3]);
    if (w <= 0 || h <= 0) {
        return OK_ATOM;
    }
    size_t needed = (size_t) w * (size_t) h * 2;
    if (term_binary_size(argv[4]) < needed) {
        RAISE_ERROR(BADARG_ATOM);
    }
    const uint8_t* data = (const uint8_t*) term_binary_data(argv[4]);
    // swap565_t is read as 16-bit words: copy an odd-aligned binary (a sub-binary can be).
    uint8_t* copy = NULL;
    if (((uintptr_t) data) & 1) {
        copy = (uint8_t*) malloc(needed);
        if (IS_NULL_PTR(copy)) {
            RAISE_ERROR(OUT_OF_MEMORY_ATOM);
        }
        memcpy(copy, data, needed);
        data = copy;
    }
    M5.Display.pushImage(x, y, w, h, (const lgfx::swap565_t*) data);
    free(copy);
    return OK_ATOM;
}
```

```ts
  // Big-endian RGB565 from base64, expanded to RGB888 by bit replication (like to_rgb888/1 in m5_emu_cmd).
  private pushImage(x: number, y: number, w: number, h: number, b64: string) {
    if (w <= 0 || h <= 0) return;
    let bytes: Uint8Array;
    try { bytes = Uint8Array.from(atob(b64), (ch) => ch.charCodeAt(0)); } catch { this.bad("push_image"); return; }
    if (bytes.length < w * h * 2) { this.bad("push_image"); return; }
    for (let j = 0; j < h; j++) for (let i = 0; i < w; i++) {
      const k = (j * w + i) * 2, v = (bytes[k] << 8) | bytes[k + 1];
      const r5 = v >> 11, g6 = (v >> 5) & 0x3f, b5 = v & 0x1f;
      this.plot(x + i, y + j, (((r5 << 3) | (r5 >> 2)) << 16) | (((g6 << 2) | (g6 >> 4)) << 8) | ((b5 << 3) | (b5 >> 2)));
    }
```

```elixir
    {:ok, _pid} = :avm_scene.start_link(Scenes.App, [], scene_opts)

    receive do
      :stop -> :ok
    end
  end

defmodule Scenes.App do
  @moduledoc "avm_scene callbacks: keeps the state and pushes the current screen's display list."
  alias Scenes.{Detail, Menu}

  def init(_args) do
    send(self(), :draw)
    {:ok, %{screen: :menu, selected: 0, icons: Scenes.Icons.all()}}
  end

  def handle_info(:draw, state), do: {:noreply, state, [{:push, render(state)}]}
  def handle_info(_msg, state), do: {:noreply, state}

  def handle_input({:button, button, event}, _ts, _pid, state) do
    case next(state, button, event) do
      ^state -> {:noreply, state}
      new_state -> {:noreply, new_state, [{:push, render(new_state)}]}
    end
  end

  def handle_input(_event, _ts, _pid, state), do: {:noreply, state}

  def handle_call(_msg, _from, state), do: {:reply, :ok, state}
  def handle_cast(_msg, state), do: {:noreply, state}

  defp next(%{screen: :menu} = s, :a, :pressed), do: %{s | selected: rem(s.selected + 1, Menu.count())}
  defp next(%{screen: :menu} = s, :b, :pressed), do: %{s | screen: :detail}
  defp next(%{screen: :detail} = s, :b, :pressed), do: %{s | screen: :menu}
  defp next(%{screen: :detail} = s, :a, :hold), do: %{s | screen: :menu}
  defp next(s, _button, _event), do: s

  defp render(%{screen: :menu} = s), do: Menu.render(s.selected, s.icons)
  defp render(%{screen: :detail} = s), do: Detail.render(s.selected)
end
```
